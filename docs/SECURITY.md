# Security Policy

## Reporting a Vulnerability

We value security for the project very highly. We encourage all users to report any vulnerabilities they discover to us.
For a vulnerability in the RelaisDesk fork or its service, report privately to Julien BELLOT EI using https://relaisdesk.fr/contact.html (the page also provides the direct email address). Do not include credentials, private keys, or customer data in public issues.

Include the affected version and commit, platform, reproduction steps, expected impact, and whether you have evidence of active exploitation. Use synthetic data. RelaisDesk coordinates relevant upstream reports with RustDesk; upstream-only issues may also be reported to info@rustdesk.com.

The maintainer assesses actively exploited vulnerabilities and severe incidents for applicable Cyber Resilience Act reporting, and personal-data breaches separately under the GDPR. An acknowledgement or a public source repository is not a security certification.

At this juncture, we don't have a bug bounty program. We are a small team trying to solve a big problem. We urge you to report any vulnerabilities responsibly
so that we can continue building a secure application for the entire community.
